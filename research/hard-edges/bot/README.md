# Бот арбитража следующего блока (Base, без своей ноды)

Состав:
- `TwoPoolArb.sol` — контракт: атомарный цикл «продать X на пуле A, откупить X на пуле B» через вложенные
  flash swap Uniswap V3 / PancakeSwap V3 / Aerodrome Slipstream. Капитал не нужен, прибыль остаётся на контракте.
  Ранний реверт `minOut`, если пул A уже сдвинули; колбэки принимаются только от ожидаемого пула; вызов только владельцем.
  Проверено на живом состоянии Base через `eth_call` с подменой кода: все 5 сочетаний пулов проходят цикл, газ ≈ 333k.
- `deploy.py` — деплой (`PRIVATE_KEY=0x... python3 deploy.py`). Стоимость на Base ≈ $0.05–0.2.
- `bot.py` — детектор и исполнитель. Публичные RPC: WebSocket `newHeads` (publicnode) + HTTP (mainnet.base.org, drpc).
  Держит состояние трёх пулов WETH/USDC (цена, ликвидность, карта тиков ±5%) по логам каждого блока,
  каждый блок решает точную задачу размера по двум пулам (тик за тиком, оба плеча), при чистой прибыли выше порога
  проверяет бандл через `eth_call` на контракте и отправляет транзакцию с priority fee.

Запуск:
```
pip install web3 websockets requests
python3 bot.py                                   # сухой режим: только журнал возможностей (bot.log.jsonl)
EXECUTOR=0x<адрес контракта> PRIVATE_KEY=0x<ключ владельца> MIN_PROFIT_USD=3 PRIORITY_GWEI=0.02 MAX_GAS_GWEI=0.05 python3 bot.py
```
Кошелёк владельца держит только ETH под газ ($10 хватает на сотни попыток). Прибыль снимается `withdraw(token, amount)`.

Вариант на flashblocks (реакция внутри блока): `bot_fb.py`, те же переменные окружения плюс
`RPC_PRECONF` (по умолчанию https://mainnet-preconf.base.org) и `PRECHECK=0`, чтобы не делать `eth_call`
перед отправкой (защита остаётся в контракте: ранний реверт `minOut`). Измерено на живом потоке:
опрос pending-логов 59 мс, отставание от кадра 60 мс, коалесинг теряет ~16% кадров при спокойном рынке.
Бэктест подхода (прокси по индексу транзакций, 5 дней, Uniswap↔Pancake): 65% окон «того же блока»
закрываются с запасом ≥3 подблока, $910/день против $64/день в слое следующего блока (верхние оценки).

Что смотреть в журнале: `opportunity` (цикл с положительной прибылью после газа), `dry_run_would_send`,
`precheck_revert` (кто-то успел раньше, транзакция не отправлена, газ не потрачен), `sent`, `receipt` (status 1 = прибыль
на контракте, 0 = проиграли гонку, потрачен газ на реверт ≈ $0.005–0.01).

Ограничения: пары только WETH/USDC на трёх пулах (легко расширить списком `POOLS`); симулятор во float (ошибка ~1e-8,
запас 0.1% в `minOut` и 50% в `minProfit`); карта тиков ±5% от цены с пересинхронизацией раз в 3000 блоков.
